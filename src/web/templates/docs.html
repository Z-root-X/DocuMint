Troubleshooting

Emails Not Sending?

If using Gmail, generate an App Password. Your normal password won't work. If using Outlook, ensure the "New Outlook" toggle is OFF.

Missing Columns?

Check your Excel file. Ensure there are no spaces in headers (e.g. "Name " vs "Name"). The system is case-insensitive but space-sensitive.
