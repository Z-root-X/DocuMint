Enterprise System Architecture

Engineered with modular Python layers separating data parsing, document compilation, dispatch, and auditing.

01

Template Merge Engine

Reads tabular datasets from Excel/CSV and parses Word (.docx) documents across both paragraph runs and tables while strictly preserving font styling.

  • • Flexible syntax: <Var>, {{Var}}, [Var]
  • • Table cell and embedded layout support
  • • Pre-flight schema validation checks
02

Universal PDF Converter

Multi-tier document conversion layer dynamically utilizing Microsoft Word COM automation, docx2pdf, or headless LibreOffice for cross-platform PDF compiling.

  • • High-fidelity vector PDF generation
  • • Cross-platform compatibility
  • • Automatic process cleanup and memory management
03

Multi-Thread Dispatcher

Asynchronous worker pool executing batch email delivery with custom SMTP/Gmail SSL configurations or native Windows Outlook automation.

  • • Parallel dispatch threads with rate-limiting
  • • Automatic personalized PDF attachment linking
  • • Full SQLite execution logging & retry audit

3-Step Operational Workflow

How DocuMint automates end-to-end document distribution from source to inbox.

1

Prepare Data and Template Files

Place your spreadsheet (student_data.xlsx) with student or employee rows, and your Word document (template.docx) containing placeholders like <Student_Name>.

2

Run Pre-Flight Validation

DocuMint validates that every variable in the Word template exists as an exact column in the Excel spreadsheet, alerting you to any misspelled or missing columns before processing.

3

Batch Generation & Dispatch

DocuMint compiles individual documents, converts each to PDF, attaches the PDF to a personalized HTML email, and dispatches the message while logging statistics to the database.
